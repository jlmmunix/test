# Icon Download Component

A professional icon set with 17 custom-designed icons for web applications, featuring download functionality for both PNG and SVG formats.

## 🚀 Quick Start

Open `icons-viewer.html` in your browser to view and download all icons immediately - no installation or build process required!

```bash
# Mac/Linux
open icons-viewer.html

# Or just double-click the file
```

## 📦 Files

- **`icons-viewer.html`** - Standalone viewer (open directly in browser)
- **`BatchImprovedIcons.jsx`** - React component version
- **`ICONS_README.md`** - Detailed documentation

## 🎨 Icon Categories

- **Actions**: Close Window, Copy, Delete, Deploy
- **Devices**: Company Devices, Device Info, Device IPs
- **Processes**: Company Processes, Deploy Process
- **UI Elements**: Dashboard Home, Execution Logs

## ✨ Features

- 40×40px PNG export
- Scalable SVG export
- Modern flat design
- Semantic color coding
- One-click downloads
