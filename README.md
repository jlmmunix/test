# Icon & UI Component Collection

A professional icon set with **64 custom-designed icons** for web applications, plus a modern Unix Deploy Tool UI design.

## 🚀 Quick Start

### Icons Viewer
Open `icons-viewer.html` in your browser to view and download all icons immediately - no installation or build process required!

```bash
# Mac/Linux
open icons-viewer.html

# Or just double-click the file
```

### UI Design Preview
Open `unix-deploy-ui-redesign.html` to see the complete Unix Deploy Tool interface design.

```bash
open unix-deploy-ui-redesign.html
```
